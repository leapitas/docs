# Vehicle Fuels

The **Vehicle Fuels** list holds the fuel codes that can be selected in **Fuel** on templates and vehicles. Open it by searching for **Vehicle Fuels** in Business Central.

The list is filled with the fuel codes from the IVI code list when the extension is installed or upgraded, for example 10 Petrol, 20 Diesel and 30 LPG.

| Field | Description |
|-------|-------------|
| **Fuel Code** | The IVI fuel code that is sent to Statens vegvesen |
| **Description** | The description of the fuel |

You can change the descriptions, for example to translate them. The fuel code is sent to Statens vegvesen as it is, so only use codes from the IVI code list.

## Restore Default Fuels

If fuel codes are missing from the list, click **Restore Default Fuels**. The missing fuel codes from the IVI code list are added. Fuels that are already in the list are not changed, so your descriptions are kept.
